# 남극 대탈출

얼음 속에서 깨어난 공룡을 피해 남극을 달려 도망치는 브라우저 게임입니다.

**플레이:** https://american211988-creator.github.io/antarctic-escape/

## 구역
400m마다 구역이 바뀌고, 네 구역을 다 지나면 처음부터 다시 돌아요(더 빨라져요).

| 구역 | 특징 |
| --- | --- |
| 빙원 | 얼음 블록, 크레바스, 펭귄 무리, 밟으면 깨지는 얇은 얼음 |
| 빙하 동굴 | 떨어지는 고드름, 슬라이드로 지나가야 하는 낮은 천장 |
| 눈보라 고원 | 굴러오는 눈덩이, 시야를 가리는 눈보라, 슬라이드로 버텨야 하는 돌풍 |
| 에레버스 화산 | 용암 틈, 하늘에서 떨어지는 화산탄, 크게 튀어 오르는 증기 분출구 |

공룡은 울부짖으며 얼음 덩어리를 떨어뜨리거나 바위를 던져요.

## 아이템
- 🐟 물고기: 점수, 상점 화폐
- ☕ 코코아: 공룡에게서 멀어짐
- 🛡 얼음 방패: 한 번 막아줌
- 🛷 썰매: 잠깐 무적 + 장애물 부수기 + 크레바스 통과
- 🧲 자석: 근처 물고기를 끌어당김

장애물을 아슬아슬하게 피하면 콤보가 쌓이고 점수 배율이 올라가요.
슬라이드로 펭귄에게 부딪히면 "펭귄 볼링"으로 물고기를 얻어요.

## 상점
모은 물고기로 보온병 코코아, 얼음 방패, 썰매 정비, 자석 장갑, 펭귄 부츠(3단 점프)를 업그레이드할 수 있어요. 기록과 업그레이드는 브라우저에 저장돼요.

## 조작
- 점프: 스페이스 / ↑ (짧게 누르면 낮게, 공중에서 한 번 더 누르면 2단 점프)
- 슬라이드: ↓ 누르고 있기 (공중에서 누르면 빨리 떨어짐)
- 일시정지: P / Esc · 소리: M
- 모바일: 화면 오른쪽 탭 = 점프, 왼쪽 누르기 = 슬라이드

## 실행
`antarctic-escape/` 폴더를 웹 서버로 열어야 해요(`game.js`를 따로 불러오기 때문).

```bash
python3 -m http.server 8765 --directory antarctic-escape
```
